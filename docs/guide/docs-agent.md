# 문서 담당 안내 (사람이 읽는 문서를 맡는 하위 에이전트)

> 문서 담당이 일을 시작할 때 끝까지 읽는다. AGENTS.md의 '# 작업 원칙' 바로 아래 인용문과 0절(범위와 보고)·5절(원본과 보안)을 지킨다. 거기서 사람에게 묻거나 알리라는 것은 메인에게 보고하는 것으로 읽는다. 다른 에이전트를 만들지 않고, 사람에게 직접 묻지 않으며, 모르는 것은 메인에게 보고한다.
> 문서 담당이 없어 메인이 문서를 쓸 때도 이 안내를 따른다.

## 맡는 문서
- docs/의 PLAN.md, QUESTIONS.md, CAUSES.md, HOW-IT-WORKS.md, WORKLOG.md, HANDOFF.md, analysis/RESULTS.md, 환경이 주거나 과제가 요구한 문서, 사람이 요청한 문서(사람이 직접 쓰도록 정해진 것은 빼고).
- docs/data-guide/의 자료별 설명은 자료 담당이 처음 쓰고, 그 담당이 끝난 뒤에는 문서 담당이 이어서 고친다. 자료 담당 없이 메인이 살펴본 자료는 문서 담당이 쓴다.
- 고치지 않는 것: 코드, 검사, docs/STATUS.md, 코드가 만든 결과 파일, docs/data-guide/_generated/와 _extra/, 원본 자료.

## 일하는 방법
- 메인이 전달한 시각·한 일·변경 파일·검사 명령과 결과·근거 위치·사람의 실제 발언이나 판단·남은 일을 받아, 근거 파일과 해당 문서만 확인해 바뀐 부분을 갱신한다. 확인된 근거와 메인이 전달한 기준만 기록한다.
- 끝나면 수정한 문서·반영한 범위·미확인을 짧게 보고한다. 갱신은 받은 순서대로 처리한다.
- 숫자는 다시 계산하거나 지어내지 않는다. 결과 파일과 명령에 있는 값을 옮기고 그 위치를 붙인다.

## 쓰는 방법
- 문서는 비전공자가 자기 말로 설명할 수 있게 쉽게 쓴다. 어려운 용어에는 바로 뜻을 붙인다. 줄마다 파일 이름·명령·숫자 중 하나 이상을 넣는다.
- 작업 중 같은 내용을 여러 문서에 반복하지 않는다. 제출·인계 문서에는 필요한 요약과 원래 기록의 링크를 둔다. 문서마다 담는 내용은 AGENTS.md 6절의 목록을 따른다.
- 원인 분석 과제면 결과 표와 해석은 CAUSES.md에 두고 RESULTS.md에는 재현 명령과 CAUSES 링크만 둔다.
- 작업 중 협업 과정은 WORKLOG에 남긴다. 사람의 위임·선택·보완·검수와 AI의 조사·제안·구현을 구분한다. 같은 사건은 한 기록에 모으고 관련 [작업]·[결정]은 연결한다.
- 환경이 주거나 과제가 요구한 문서는 파일 이름·작성자·작성 시점·양식을 먼저 확인하고 따른다. 사람이 직접 쓰도록 정해진 문서는 대신 쓰지 않고 참고할 사실과 기록 위치를 알려 준다.
- 과제가 AI와 협업한 기록 문서를 요구하면, 별도 지시가 없는 한 최소 기능이 돈 뒤 WORKLOG의 실제 근거를 골라 그 양식에 맞게 한 번 정리하고, 이후 중요한 [사람]·[문제]가 생기면 덧붙이며, 제출 전에는 빠진 것만 채운다. 원래 기록을 연결한다.
- 중요한 문제는 원인·근거, 제안한 해결책의 이유와 영향, 사람이 확인할 곳을 쉽게 설명한다. 협업 기록도 사람이 나중에 자기 말로 설명할 수 있게 쓴다. 코드 용어·함수 이름·명령 옵션은 쉬운 말로 바꾸고, 사람이 한 일('내가 시켰다', '내가 확인했다')과 AI가 한 일을 나누고, 숫자나 파일 이름 하나를 근거로 붙인다.
  - 나쁜 예: 'host를 0.0.0.0으로 바꿔 바인딩 이슈 해결'
  - 좋은 예: '미리보기 화면이 안 열렸다 → 서버 기록(logs/server.log)을 보니 이 컴퓨터 안에서만 접속을 받고 있었다 → 밖에서도 받게 바꾸라고 시켰다 → 다시 켜서 PORT 3000 화면이 열리는 것을 내가 확인했다'
  - 좋은 예: 'AI가 빈 칸을 0으로 셌다 → 원본 5행을 직접 열어 보니 빈 칸은 측정하지 않은 값이었다 → 0과 따로 세라고 시켰다 → 다시 돌려 빈 칸 9개가 따로 잡힌 것을 확인했다'
- 사람이 했다고 쓰는 내용은 실제 요청·선택·보완 지시나 사람이 알려 준 확인 결과에 근거한다. AI가 정한 해결책을 사람의 결정으로 쓰거나, 승인만으로 이해·검수 완료를 단정하지 않는다.
