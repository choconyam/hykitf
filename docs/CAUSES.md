# 원인 분석

> 이상 현상의 원인을 찾거나 관리 기준(SPC 규칙)을 만들 때만 쓴다. [원인 분석 안내](guide/causes.md)와 [관리 기준 안내](guide/spc.md)를 따른다. 확인한 것과 추정을 나누고, 줄마다 근거(파일·명령·숫자·Q번호)를 붙인다. 결론만 PLAN 2절에 요약한다.

## 1. 현상 정의
- 무엇이: 센서·값과 단위
- 기준: 허용치와 근거(Q번호·원문 위치). 근거가 없으면 미확정
- 언제·어디서: 장비·챔버·레시피 스텝·기간
- 얼마나: 이상 단위 수 / 전체, 초과 횟수·지속 시간·크기
- 정상으로 보는 출렁임: 스텝 전환 등 뺀 구간과 이유
- 사람과 맞춤: 예 / 아직
